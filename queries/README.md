# Phase 5 - Queries
### MageHand_Casters
This query allows you to see which classes can learn the spell "Mage Hand". It can be modified to list any spell and class that can cast it.

### Wizard_Necromancer
This query displays the complete list of what Wizard spells go into the necromancy school. It can be modified to list any school of magic.

### Bard_Cantrips
This query displays the cantrips that can be learned by the Bard class. It can be modified to list any cantrips of any class.

### Dice_Filter
This query displays different Spells damage type, dice, and amount of dice rolled. It can be modified to list any die. I've set the JOIN to LEFT, because there are some spells that don't deal damage, but still require the use of a die.

### Effect_Filter
This query allows you to list the spells of a certain effect. It can be modified to list any effect.

### School-counter
This query returns the total number of spells in every school, sorted by largest to smallest.

### Dice-max
This query which spells rolls the most amount of dice in each level.

### Non-violent
This query shows every spell that doesn't deal any damage.

### Attack-roll
This query shows every spell that has an attack roll rather than a saving throw.

### Concentration-count
This query displays the number of concentration spells in each class.
